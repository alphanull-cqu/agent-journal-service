# agent-journal-service
组织级代码变更监听与研发过程记录服务
# Agent Journal 使用说明

本组织使用 Agent Journal 自动记录项目开发过程。

组织中新建的 GitHub 仓库会自动加入 `AGENTS.md`。使用桌面端 Codex 修改项目时，Codex会根据该文件的要求，将本次任务的目标、修改过程、修改内容、问题和验证结果记录到：

```
.agent-journal/DEVELOPMENT_JOURNAL.md
```

开发日志需要和本次代码一起提交到 GitHub。

## 当前已经可用的功能

目前已经完成并验证以下流程：

* 新仓库自动加入 `AGENTS.md`
* 桌面端 Codex 自动读取项目要求
* 修改代码时自动创建开发日志
* 自动记录修改内容和测试结果
* 开发日志与代码一起提交和推送
* 已有开发日志不会在后续任务中被主动删除

## 新建项目

当前建议在 GitHub 组织中创建仓库时勾选：

```
Add a README file
```

仓库创建后，等待 GitHub App 自动提交 `AGENTS.md`。

确认仓库根目录出现以下文件后，再开始开发：

```
AGENTS.md
README.md
```

如果仓库创建后没有看到 `AGENTS.md`，请先刷新页面或等待一段时间。仍未出现时，请联系项目管理员，不要直接开始开发。

## 获取项目

第一次参与项目时执行：

```
git clone 仓库地址
```

进入项目目录后确认存在：

```
AGENTS.md
```

如果本地已经有该仓库，每次开始新任务前执行：

```
git pull
```

这样可以获得最新代码、项目要求和其他成员提交的开发日志。

## 使用桌面端 Codex

在桌面端 Codex 中打开项目的根目录。

必须直接选择包含 `AGENTS.md` 的仓库文件夹，不要只打开某个子目录，也不要选择多个项目共同所在的上级目录。

打开项目后，可以先发送：

```
不要修改任何文件。请告诉我当前项目加载了哪些项目级指令文件，并概括核心要求。
```

Codex正常情况下应当识别项目根目录中的 `AGENTS.md`。

确认成功后，按照正常方式向 Codex描述开发任务即可，不需要在每个任务中重复要求它写开发日志。

## 完成任务后

Codex完成代码修改后，成员需要检查：

```
git status --short
```

除本次代码、文档和配置变更外，通常还应看到：

```
.agent-journal/DEVELOPMENT_JOURNAL.md
```

检查开发日志中是否包含：

* 本次任务目标
* 修改过程
* 修改的文件和主要内容
* 遇到的问题及处理方式
* 测试或验证结果
* 尚未完成的事项

确认内容正确后，将代码和开发日志一起提交：

```
git add .
git commit -m "本次任务的提交说明"
git push
```

不要只提交代码而遗漏开发日志。

## 后续修改

每次开始新任务前先执行：

```
git pull
```

Codex应当继续在原有的：

```
.agent-journal/DEVELOPMENT_JOURNAL.md
```

末尾追加新记录，不应删除、覆盖或重写以前的记录。

如果发现历史内容被修改，应停止提交并恢复原有日志。

## 使用要求

成员需要遵守以下要求：

* 使用桌面端 Codex 时，从项目根目录打开仓库。
* 开始任务前先拉取远程最新内容。
* 代码和开发日志必须一起提交。
* 提交前检查开发日志内容是否准确。
* 不得删除或覆盖历史开发日志。
* 不得在日志中写入密码、Token、私钥或其他敏感信息。
* 只查看和分析项目、没有修改文件时，不需要写开发日志。

## 当前限制

### 已完成的本地项目暂不建议直接推送到空仓库

如果项目已经在本地完成，然后才在 GitHub 组织中创建空仓库并进行第一次推送，当前版本可能无法自动加入 `AGENTS.md`。

遇到这种情况，请在第一次推送后检查远程仓库中是否存在 `AGENTS.md`。如果不存在，请联系项目管理员完成初始化。

### 手动开发不会自动记录完整过程

当前开发日志主要由 Codex根据 `AGENTS.md` 生成。

如果完全手动修改代码，或者使用不支持 `AGENTS.md` 的开发工具，开发日志不会自动生成。

### 当前只验证了桌面端 Codex

目前已经完成桌面端 Codex 的实际测试。其他代码智能体是否能够正确读取并遵守 `AGENTS.md`，需要分别测试。

### 日志需要人工检查

Codex生成的日志可能存在遗漏或描述不准确的情况。

成员在提交前仍需检查日志，但只能修正本次新增记录，不能删除或重写以前的历史记录。

## 常见问题

### 仓库里没有 AGENTS.md

先执行：

```
git pull
```

如果 GitHub 远程仓库中也不存在该文件，请联系项目管理员。

### 修改代码后没有开发日志

确认桌面端 Codex 打开的是项目根目录，并让 Codex说明当前加载的项目级指令文件。

如果没有识别到 `AGENTS.md`，请重新打开正确的仓库目录并新建一个 Codex 对话。

### 推送时提示远程仓库有新提交

GitHub App 或其他成员可能已经提交了新内容。

先执行：

```
git pull --rebase
```

处理完成后再执行：

```
git push
```
